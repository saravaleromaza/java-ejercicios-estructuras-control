# Ejercicios Java: estructuras de control

20 ejercicios de programación en Java sobre condicionales y bucles.

## Contenido
- Condicionales: positivo/negativo, múltiplos, ordenar tres números, notas
- Bucles `while` y `do-while`: juego de adivinar un número, sumas y medias
- Bucles `for`: factorial, tablas de multiplicar, números primos
- Bucles anidados y contadores

## Cómo ejecutarlo
Compila y ejecuta la clase `EjerciciosTarea4Complementaria` (paquete `tarea4`).
Los ejercicios se ejecutan uno detrás de otro desde el `main`.
